## 2차 (2026-11-07) — 타깃·톤 재설정: 10~20대 여성, 귀엽고 센티멘탈, "트러블엔 이 제품" 각인
- 비주얼: 라벤더 밤하늘 파스텔 팔레트, 둥근 서체(Fredoka/Jua + Nunito/Gowun Dodum + 손글씨 Caveat/Gaegu), 키키 리디자인(큰 눈·리본·하트 파자마), 요정 보틀에 얼굴, 저주 파스텔화, 콤보 하트 파티클
- 교육 장치: 시작 시 '내 피부 고민' 선택(최대 2, 해당 저주 1.8배 등장 + 매칭 요정 미리 안내) → 저주 첫 등장마다 '요정의 속삭임'(성분·제품 한 줄) → 밤 요약 '오늘 밤의 레슨' 플래시카드 → 결과 '나의 피부 매치' 제품 2개 추천(이유 표시) → 요정 앨범(성격·키키의 메모)
- 스토리: 7박 일기 전면 교체(친구·할머니·아빠·첫사랑·프롬), 엔딩 메시지("비밀은 요정이 아니라 매일 밤의 돌봄")
- 공유: 인스타 4:5 공유 카드(캔버스 생성) + 이미지 저장/공유/캡션 복사

- 밸런스: 1번째 밤을 더 느리게(등장 2.8초·성장 8초)
